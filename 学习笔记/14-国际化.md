# PlatformBase 国际化 (i18n) — 手把手教学笔记

---

## 一、国际化 vs 本地化

| 术语 | 英文 | 含义 |
|------|------|------|
| 国际化 | i18n (Internationalization) | 让代码支持多种语言（架构设计） |
| 本地化 | l10n (Localization) | 为特定语言提供翻译资源（具体数据） |

**本项目：** 使用 ASP.NET Core 内置的 `IStringLocalizer` + `.resx` 资源文件，支持中文和英文两种语言。

---

## 二、配置

### 2.1 Program.cs 注册

```csharp
// 注册本地化服务
builder.Services.AddLocalization();

// 配置支持的语言和文化
builder.Services.Configure<RequestLocalizationOptions>(options =>
{
    options.DefaultRequestCulture = new RequestCulture("zh-CN");  // 默认中文
    options.SupportedCultures = [
        new CultureInfo("zh-CN"),
        new CultureInfo("en")
    ];
    options.SupportedUICultures = [
        new CultureInfo("zh-CN"),
        new CultureInfo("en")
    ];

    // 从 Accept-Language 请求头读取语言偏好
    options.RequestCultureProviders = [
        new AcceptLanguageHeaderRequestCultureProvider()
    ];
});

// 中间件注册
app.UseRequestLocalization();   // 必须在路由之前
```

### 2.2 中间件顺序

```
app.UseSerilogRequestLogging();    // ① 请求日志
app.UseRequestLocalization();      // ② 设置当前线程的 CultureInfo
app.UseRouting();                  // ③ 路由
...
```

请求到达时，`UseRequestLocalization` 解析 `Accept-Language: zh-CN,en;q=0.9`，设置 `Thread.CurrentThread.CurrentCulture` 和 `CurrentUICulture`，后续所有 `IStringLocalizer` 查找自动使用对应语言的 `.resx` 文件。

## 四、使用方式

### 4.1 注入与调用

```csharp
// AuthService.cs
public class AuthService : IAuthService
{
    private readonly IStringLocalizer<SharedResource> _localizer;

    public AuthService(IStringLocalizer<SharedResource> localizer, ...)
    {
        _localizer = localizer;
    }

    public async Task<LoginResult> LoginAsync(LoginRequest request)
    {
        var user = await FindUser(request.Username);
        if (user == null)
        {
            // 根据 Accept-Language 自动返回对应语言
            return LoginResult.Fail(_localizer["用户名或密码错误"]);
        }

        if (user.LockoutEnd > DateTime.UtcNow)
        {
            var minutes = Math.Ceiling((user.LockoutEnd.Value - DateTime.UtcNow).TotalMinutes);
            // 支持格式化参数
            return LoginResult.Fail(
                _localizer["登录尝试次数过多，请{0}分钟后重试", minutes]);
        }
    }
}
```

### 4.2 请求效果

```bash
# 中文用户
curl -H "Accept-Language: zh-CN" -X POST /api/auth/login ...
# {"code":401,"message":"用户名或密码错误"}

# 英文用户
curl -H "Accept-Language: en" -X POST /api/auth/login ...
# {"code":401,"message":"Invalid username or password"}

# 未指定语言 → 默认 zh-CN
curl -X POST /api/auth/login ...
# {"code":401,"message":"用户名或密码错误"}
```

## 五、添加新语言的步骤

### 步骤 1：添加语言支持

```csharp
// Program.cs 中
options.SupportedCultures = [
    new CultureInfo("zh-CN"),
    new CultureInfo("en"),
    new CultureInfo("ja")       // 新增日语
];
```

### 步骤 2：创建资源文件

```
Resources/
├── SharedResource.cs              ← 标记类
├── SharedResource.zh-CN.resx      ← 中文
├── SharedResource.en.resx         ← 英文
└── SharedResource.ja.resx         ← 日语（新增）
```

### 步骤 3：在 .resx 中添加翻译

## 六、设计要点

### 6.1 为什么 key 用中文？

```
传统方案:  key="Error.InvalidCredentials"
本地方案:  key="用户名或密码错误"

优势: 代码自文档化，不需要对照表就知道含义
劣势: key 较长，但 .resx 编辑器支持，不是问题
```

### 6.2 为什么用 IStringLocalizer<SharedResource>？

```
IStringLocalizer<SharedResource>  → 查找 SharedResource.{culture}.resx
IStringLocalizer<Controller>      → 查找 Controllers.Controller.{culture}.resx

本项目只用 SharedResource 作为标记类，所有翻译集中在一个文件中。
如果需要模块化，可以用多个标记类。
```

## 七、架构全景图

```
HTTP 请求
  Accept-Language: zh-CN,en;q=0.9
    │
    ▼
UseRequestLocalization() 中间件
    │ 解析 Accept-Language
    │ 设置 Thread.CurrentThread.CurrentCulture = zh-CN
    │ 设置 Thread.CurrentThread.CurrentUICulture = zh-CN
    │
    ▼
IStringLocalizer<SharedResource>["用户名或密码错误"]
    │
    ├─ 当前 Culture = zh-CN → 查找 SharedResource.zh-CN.resx
    │   → "用户名或密码错误"
    │
    └─ 当前 Culture = en → 查找 SharedResource.en.resx
        → "Invalid username or password"

资源文件命名规则:
  SharedResource.{culture}.resx
  SharedResource.zh-CN.resx  ← 中立文化（中国区域但支持中文）
  SharedResource.en.resx     ← 英文
```

│              国际化 黄金法则                                     │
├─────────────────────────────────────────────────────────────────┤
│  1. 用 IStringLocalizer<SharedResource> 而非直接 .resx 读取     │
│  2. key 用中文（代码自文档化）                                  │

│  5. DefaultRequestCulture = "zh-CN"（默认中文）                 │
│  6. AcceptLanguageHeaderRequestCultureProvider 自动解析请求头    │
│  7. UseRequestLocalization 在 UseRouting 之前                   │
│  8. 新增语言只需：加 CultureInfo + 建 .resx 文件 + 写翻译        │
│  9. 错误提示应国际化，开发调试日志不需要                         │
│ 10. .resx 文件编译为嵌入资源，运行时无需文件系统依赖              │
└─────────────────────────────────────────────────────────────────┘
