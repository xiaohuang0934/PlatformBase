# PlatformBase 多数据库配置 + UnitOfWork — 手把手教学笔记

## 一、为什么需要多数据库支持？

不同场景需要不同数据库：

| 场景 | 推荐数据库 | 原因 |
|------|-----------|------|
| 开发环境 / 单机部署 | SQLite | 零配置，文件存储，无需安装 |
| 企业生产环境 | SQL Server | 完整 ACID，商业支持 |
| 云原生 / Linux | MySQL | 开源免费，云服务广泛支持 |

**核心需求：** 只改一个配置项，不修改任何代码，即可切换数据库。

## 四、AddDatabase 扩展方法

```csharp
// PlatformBase.Infrastructure/Extensions/ServiceCollectionExtensions.cs
using Microsoft.EntityFrameworkCore;
using PlatformBase.Core;
using PlatformBase.Core.Repositories;
using PlatformBase.Infrastructure.Data;

public static class ServiceCollectionExtensions
{
    /// <summary>
    /// 注册数据库上下文和工作单元。
    /// 根据 DatabaseProvider 自动配置对应的 EF Core 数据库驱动。
    /// </summary>
    public static IServiceCollection AddDatabase(
        this IServiceCollection services,
        DatabaseProvider provider,
        string connectionString,
        bool enableSensitiveDataLogging = false)
    {
        // ① 注册 AppDbContext
        services.AddDbContext<AppDbContext>(options =>
        {
            switch (provider)
            {
                case DatabaseProvider.SqlServer:
                    options.UseSqlServer(connectionString);
                    break;
                case DatabaseProvider.MySql:
                    options.UseMySql(connectionString,
                        ServerVersion.AutoDetect(connectionString));
                    break;
                case DatabaseProvider.Sqlite:
                default:
                    options.UseSqlite(connectionString);
                    break;
            }

            if (enableSensitiveDataLogging)
                options.EnableSensitiveDataLogging();
        });

        // ② 注册工作单元
        services.AddScoped<IUnitOfWork, UnitOfWork>();

        return services;
    }
}
```

## 五、IUnitOfWork 接口（完整实现）

```csharp
// PlatformBase.Core/Repositories/IUnitOfWork.cs
using PlatformBase.Core.Entities;

namespace PlatformBase.Core.Repositories;

/// <summary>
/// 工作单元契约，管理数据库事务和仓储实例的生命周期。
/// </summary>
public interface IUnitOfWork : IDisposable, IAsyncDisposable
{
    /// <summary>获取指定实体类型的仓储实例（惰性创建，同一次工作单元内复用）</summary>
    IRepository<T> Repository<T>() where T : BaseEntity;

    /// <summary>获取指定泛型主键实体类型的仓储实例</summary>
    IKeyedRepository<T, TKey> KeyedRepository<T, TKey>()
        where T : BaseEntity<TKey> where TKey : struct;

    /// <summary>提交所有变更到数据库</summary>
    Task<int> SaveChangesAsync(CancellationToken cancellationToken = default);

    /// <summary>开启数据库事务</summary>
    Task BeginTransactionAsync(CancellationToken cancellationToken = default);

    /// <summary>提交事务</summary>
    Task CommitTransactionAsync(CancellationToken cancellationToken = default);

    /// <summary>回滚事务</summary>
    Task RollbackTransactionAsync(CancellationToken cancellationToken = default);
}
```

## 六、UnitOfWork 实现（完整）

```csharp
// PlatformBase.Infrastructure/Data/UnitOfWork.cs
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Storage;
using PlatformBase.Core.Entities;
using PlatformBase.Core.Repositories;
using PlatformBase.Infrastructure.Repositories;

namespace PlatformBase.Infrastructure.Data;

/// <summary>
/// 工作单元实现。
/// 封装 DbContext 事务管理和仓储实例的惰性创建。
/// </summary>
public class UnitOfWork : IUnitOfWork
{
    private readonly AppDbContext _context;

    // Key=实体Type, Value=EfRepository<T> 实例 → 同类型在同一次 UoW 内复用
    private readonly Dictionary<Type, object> _repositories = new();

    // 当前活跃的数据库事务（可能为 null）
    private IDbContextTransaction? _transaction;

    public UnitOfWork(AppDbContext context)
    {
        _context = context;
    }

    // ──────── 仓储惰性创建 ────────
    public IRepository<T> Repository<T>() where T : BaseEntity
    {
        var type = typeof(T);                             // 以实体类型为 key
        if (!_repositories.ContainsKey(type))              // 尚未创建
            _repositories[type] = new EfRepository<T>(_context);  // 惰性实例化

        return (IRepository<T>)_repositories[type];        // 返回已缓存的实例
    }

    public IKeyedRepository<T, TKey> KeyedRepository<T, TKey>()
        where T : BaseEntity<TKey> where TKey : struct
    {
        var type = typeof(T);
        if (!_repositories.ContainsKey(type))
            _repositories[type] = new EfKeyedRepository<T, TKey>(_context);

        return (IKeyedRepository<T, TKey>)_repositories[type];
    }

    // ──────── 持久化 ────────
    public async Task<int> SaveChangesAsync(CancellationToken ct = default)
        => await _context.SaveChangesAsync(ct);

    // ──────── 事务管理 ────────
    public async Task BeginTransactionAsync(CancellationToken ct = default)
        => _transaction = await _context.Database.BeginTransactionAsync(ct);

    public async Task CommitTransactionAsync(CancellationToken ct = default)
    {
        if (_transaction != null)
        {
            await _transaction.CommitAsync(ct);
            await _transaction.DisposeAsync();
            _transaction = null;
        }
    }

    public async Task RollbackTransactionAsync(CancellationToken ct = default)
    {
        if (_transaction != null)
        {
            await _transaction.RollbackAsync(ct);
            await _transaction.DisposeAsync();
            _transaction = null;
        }
    }

    // ──────── 资源释放 ────────
    public void Dispose()
    {
        _transaction?.Dispose();
        _context.Dispose();
    }

    public async ValueTask DisposeAsync()
    {
        if (_transaction != null)
            await _transaction.DisposeAsync();
        await _context.DisposeAsync();
    }
}
```

## 七、UnitOfWork 实战

### 7.1 基本使用

```csharp
public class UserService
{
    private readonly IUnitOfWork _uow;

    public UserService(IUnitOfWork uow) { _uow = uow; }

    public async Task CreateUserAsync(CreateUserDto dto)
    {
        var userRepo = _uow.Repository<User>();       // 获取 User 仓储
        var roleRepo = _uow.Repository<Role>();        // 获取 Role 仓储

        var user = new User { Username = dto.Username };
        userRepo.Add(user);

        var role = new Role { Name = "默认角色" };
        roleRepo.Add(role);

        await _uow.SaveChangesAsync();  // 一次提交，两个 INSERT 在同一事务中
    }
}
```

### 7.2 跨仓储事务

```csharp
public async Task TransferAsync(Guid fromId, Guid toId, decimal amount)
{
    await _uow.BeginTransactionAsync();   // 开启事务

    try
    {
        var accountRepo = _uow.Repository<Account>();

        var from = await accountRepo.GetByIdAsync(fromId);
        from.Balance -= amount;
        accountRepo.Update(from);

        var to = await accountRepo.GetByIdAsync(toId);
        to.Balance += amount;
        accountRepo.Update(to);

        await _uow.SaveChangesAsync();
        await _uow.CommitTransactionAsync();  // 提交事务
    }
    catch
    {
        await _uow.RollbackTransactionAsync(); // 回滚
        throw;
    }
}
```

### 7.3 仓储复用（同类型不重复创建）

```csharp
var repo1 = _uow.Repository<User>();  // 创建 EfRepository<User>
var repo2 = _uow.Repository<User>();  // 返回同一个实例
var repo3 = _uow.Repository<Role>();  // 不同类型 → 创建新实例

// repo1 == repo2  → true  (同类型复用)
// repo1 != repo3  → true  (不同类型)
```

## 八、Hangfire 数据库适配

```csharp
// PlatformBase.Host/Extensions/HangfireExtensions.cs
public static IServiceCollection AddHangfireInfrastructure(
    this IServiceCollection services,
    DatabaseProvider dbProvider,
    string connectionString)
{
    services.AddHangfire(config =>
    {
        if (dbProvider == DatabaseProvider.SqlServer)
            config.UseSqlServerStorage(connectionString);   // 持久化
        else
            config.UseMemoryStorage();                      // 内存（重启丢失）
    });

    services.AddHangfireServer(options =>
    {
        options.WorkerCount = Environment.ProcessorCount * 2;
        options.Queues = ["default"];
    });

    return services;
}
```

## 九、Program.cs 调用

```csharp
// ① 读取配置（有优先级兜底）
var dbProvider = Enum.Parse<DatabaseProvider>(
    builder.Configuration["Database:Provider"] ?? "Sqlite");

var connectionString = builder.Configuration.GetConnectionString("DefaultConnection")
    ?? builder.Configuration["Database:ConnectionString"] ?? "Data Source=app.db";

var enableSensitiveLogging = builder.Configuration.GetValue<bool>(
    "Database:EnableSensitiveDataLogging");

// ② 注册 EF Core + UnitOfWork
builder.Services.AddDatabase(dbProvider, connectionString, enableSensitiveLogging);

// ③ 注册 Hangfire（同一个 dbProvider）
builder.Services.AddHangfireInfrastructure(dbProvider, connectionString);
```

## 十一、架构全景图

```
appsettings.json / 环境变量
  Database:Provider = Sqlite|SqlServer|MySql
            │
  ┌─────────┴─────────┐
  ▼                   ▼
AddDatabase        AddHangfireInfra
  │                   │
  ├─ switch(provider) ├─ if SqlServer → SqlServerStorage
  │  SqlServer        └─ else → MemoryStorage
  │  MySql
  │  Sqlite
  │
  └─ AddScoped<IUnitOfWork, UnitOfWork>
       │
       ├─ Repository<T>() → 惰性创建 EfRepository<T>
       ├─ SaveChangesAsync()
       ├─ Begin / Commit / Rollback
       └─ Dispose → 释放 DbContext + Transaction
```

## 十二、最佳实践速查卡

```
┌─────────────────────────────────────────────────────────────────┐
│           多数据库 + UnitOfWork 黄金法则                          │
├─────────────────────────────────────────────────────────────────┤
│  1. 配置与代码分离：改 JSON/环境变量，不动代码                    │
│  2. Sqlite 是 default 分支（双重兜底）                            │
│  3. Repository<T>() 惰性创建 + Dictionary 缓存复用                │
│  4. 跨仓储操作用 BeginTransaction/Commit/Rollback                │
│  5. Commit 后自动 Dispose Transaction（防泄漏）                   │
│  6. Hangfire SQLite/MySql 降级为 MemoryStorage                    │
│  7. EnableSensitiveDataLogging 仅开发环境开启                     │
│  8. IUnitOfWork 实现 IDisposable + IAsyncDisposable（双释放）     │
│  9. 连接字符串优先级：ConnectionStrings > Database 节点 > 硬编码   │
│ 10. AddDatabase 和 AddHangfireInfra 使用同一个参数                │
└─────────────────────────────────────────────────────────────────┘
```
