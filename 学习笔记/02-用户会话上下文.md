## 一、为什么需要用户上下文？

在每个 HTTP 请求中，所有代码层（Controller / Service / DbContext）都需要知道两件事：
- **谁在操作**（身份信息）
- **操作哪个租户的数据**（数据范围）

`ICurrentUserContext` 把这两个职责整合在一个接口中，通过 DI 注入，一行代码获取所有信息。

## 二、数据来源全景

```
HTTP 请求
  │
  ├─ JWT Token (Authorization: Bearer ...)
  │    └── ClaimsPrincipal (HttpContext.User)
  │         ├── ClaimTypes.NameIdentifier   → UserId
  │         ├── ClaimTypes.Name             → UserName
  │         ├── ClaimTypes.Email            → Email
  │         ├── ClaimTypes.Role (多个)       → Roles
  │         ├── "user_type"                 → IsSuperAdmin
  │         ├── "tenant_id"                 → 租户用户归属租户
  │         └── "client_id"                 → ClientId
  │
  ├─ HttpContext.Connection.RemoteIpAddress  → IpAddress
  │
  ├─ DTO 参数（前端传入）                     → SetCurrentTenant(tenantId)
  │
  └─ PlatformUserTenants 表（DB 查询）        → 管理员已分配租户列表
```

## 三、接口定义

```csharp
// PlatformBase.Core/Services/ICurrentUserContext.cs
public interface ICurrentUserContext
{
    // ═══════ 身份信息（只读，来自 JWT）═══════
    Guid?               UserId { get; }
    string?             UserName { get; }
    string?             Email { get; }
    IReadOnlyList<string> Roles { get; }
    bool                IsAuthenticated { get; }
    string?             IpAddress { get; }
    string?             ClientId { get; }
    bool                IsSuperAdmin { get; }

    // ═══════ 租户范围（Controller 可写）═══════
    Guid?               CurrentTenantId { get; }
    IReadOnlyList<Guid> AccessibleTenantIds { get; }

    // ═══════ 操作方法 ═══════
    void SetCurrentTenant(Guid? tenantId);
    bool HasAccess(Guid tenantId);
}
```

## 四、完整实现

```csharp
// PlatformBase.Host/Services/UserModule/CurrentUserContext.cs
using System.Security.Claims;
using Microsoft.EntityFrameworkCore;
using PlatformBase.Core.Entities;
using PlatformBase.Core.Services;
using PlatformBase.Infrastructure.Data;

public class CurrentUserContext : ICurrentUserContext
{
    private readonly IHttpContextAccessor _httpContextAccessor;
    private List<Guid>? _accessibleIds;
    private Guid? _currentTenantId;

    public CurrentUserContext(IHttpContextAccessor httpContextAccessor)
    {
        _httpContextAccessor = httpContextAccessor;
    }

    private ClaimsPrincipal? User => _httpContextAccessor.HttpContext?.User;

    // ═══════════════════ 身份信息 ═══════════════════
    public Guid? UserId =>
        Guid.TryParse(User?.FindFirstValue(ClaimTypes.NameIdentifier), out var id) ? id : null;
    public string? UserName => User?.FindFirstValue(ClaimTypes.Name);
    public string? Email => User?.FindFirstValue(ClaimTypes.Email);
    public IReadOnlyList<string> Roles =>
        User?.FindAll(ClaimTypes.Role).Select(c => c.Value).ToList() ?? [];
    public bool IsAuthenticated => User?.Identity?.IsAuthenticated ?? false;
    public string? IpAddress =>
        _httpContextAccessor.HttpContext?.Connection.RemoteIpAddress?.ToString();
    public string? ClientId => User?.FindFirstValue("client_id");
    public bool IsSuperAdmin =>
        int.TryParse(User?.FindFirstValue("user_type"), out var ut)
        && ut == (int)UserType.PlatformAdmin;

    // ═══════════════════ 租户范围 ═══════════════════
    public Guid? CurrentTenantId
    {
        get
        {
            if (_currentTenantId != null) return _currentTenantId;
            if (!IsAuthenticated || UserId == null) return null;
            if (IsSuperAdmin) return null;
            var raw = User?.FindFirstValue("tenant_id");
            return Guid.TryParse(raw, out var tid) ? tid : null;
        }
    }

    /// <summary>仅平台管理员可调用。设置后自动清除缓存。</summary>
    public void SetCurrentTenant(Guid? tenantId)
    {
        if (!IsSuperAdmin) return;
        _currentTenantId = tenantId;
        _accessibleIds = null;
    }

    /// <summary>根据用户类型 + CurrentTenantId 动态计算可访问范围</summary>
    public IReadOnlyList<Guid> AccessibleTenantIds
    {
        get
        {
            if (_accessibleIds != null) return _accessibleIds;
            if (!IsAuthenticated || UserId == null) return _accessibleIds = [];
            if (IsSuperAdmin && _currentTenantId != null)
                return _accessibleIds = [_currentTenantId.Value];
            if (IsSuperAdmin)
                return _accessibleIds = LoadAssignedTenants();
            var raw = User?.FindFirstValue("tenant_id");
            _accessibleIds = Guid.TryParse(raw, out var tid) ? [tid] : [];
            return _accessibleIds;
        }
    }

    /// <summary>校验是否有权访问指定租户</summary>
    public bool HasAccess(Guid tenantId)
    {
        if (!IsAuthenticated || UserId == null) return false;
        if (IsSuperAdmin)
        {
            _accessibleIds ??= LoadAssignedTenants();
            return _accessibleIds.Contains(tenantId);
        }
        var raw = User?.FindFirstValue("tenant_id");
        return Guid.TryParse(raw, out var tid) && tid == tenantId;
    }

    private List<Guid> LoadAssignedTenants()
    {
        try
        {
            var db = _httpContextAccessor.HttpContext?.RequestServices
                .GetService<AppDbContext>();
            if (db == null) return [];
            return db.PlatformUserTenants
                .AsNoTracking()
                .Where(p => p.PlatformUserId == UserId!.Value)
                .Select(p => p.TenantId)
                .ToList();
        }
        catch { return []; }
    }
}
```

## 六、使用示例

### Controller 中 — 前端传入 TenantId

```csharp
[HttpGet]
public async Task<ApiResult> GetUsers([FromQuery] Guid? tenantId)
{
    // ① 校验权限
    if (tenantId.HasValue && !_context.HasAccess(tenantId.Value))
        return ApiResult.Fail(ErrorCode.Forbidden, "无权访问该租户");

    // ② 写入上下文 → EF Core 过滤器自动生效
    _context.SetCurrentTenant(tenantId);

    // ③ Service 层直接查，不需手动传租户
    return ApiResult.Success(await _service.GetPagedAsync());
}
```

## 七、数据流全链路

```
前端选择"租户A"
  │
  ├─ GET /api/v1/tenants/accessible  → [ { id, name }, ... ]
  ├─ 用户选择 tenant-a
  │
  ▼
GET /api/v1/users?tenantId=tenant-a-id
  │
  ▼
Controller:
  HasAccess(tenant-a-id) → PlatformUserTenants 表校验 ✅
  SetCurrentTenant(tenant-a-id)
  │
  ▼
EF Core 全局过滤器:
  WHERE TenantId IN (AccessibleTenantIds)
  = WHERE TenantId IN ('tenant-a-id')
  │
  ▼
返回租户A的所有用户（看不到租户B的数据）
```

## 八、安全约束表

| 调用者 | SetCurrentTenant(x) | HasAccess(x) | AccessibleTenantIds |
|--------|:---:|:---:|------|
| 平台管理员（未选择） | ✅ 可设 | ✅ 查 PlatformUserTenants | 全部已分配租户 |
| 平台管理员（已选择） | ✅ 可改 | ✅ 查 PlatformUserTenants | [当前租户] |
| 租户用户 | ❌ 忽略 | ✅ 仅自身 tenant_id | [自身租户] |
| 未认证 | ❌ 忽略 | ❌ 返回 false | [] |

## 九、与旧版比较

| | 旧 ICurrentUserContext | 新 ICurrentUserContext |
|---|---|---|
| 数据来源 | X-Tenant-Id Header | DTO 参数（Swagger 可见） |
| 租户 ID 属性 | `TenantId`（只读） | `CurrentTenantId`（可 set） |
| 权限校验 | 无 | `HasAccess(Guid)` |
| 前端对接 | 需在所有请求加 Header | 标准参数传递 |
| 接口数量 | 1 个接口 | 1 个接口（身份+租户合并） |
| X-Tenant-Id | 依赖 | 不再需要 |

## 十、最佳实践速查卡

```
┌─────────────────────────────────────────────────────────────────┐
│          ICurrentUserContext 黄金法则                            │
├─────────────────────────────────────────────────────────────────┤
│  1. AddScoped — 每次 HTTP 请求一个实例                           │
│  2. AddHttpContextAccessor 在 AddDatabase 之前注册               │
│  3. SetCurrentTenant 仅平台管理员生效（租户用户调用被忽略）      │
│  4. HasAccess 用于 Controller 中校验 DTO 传入的 tenantId         │
│  5. CurrentTenantId 是 get+set 属性，替代旧的只读 TenantId       │
│  6. 前端通过 GET /api/v1/tenants/accessible 获取下拉框数据源      │
│  7. AccessibleTenantIds 带字段缓存，SetCurrentTenant 自动刷新     │
│  8. 不注入 AppDbContext（通过 IServiceProvider 延迟解析）         │
│  9. LoadAssignedTenants 异常时返回空列表（不中断请求）            │
│ 10. JWT 中仍保留 tenant_id Claim（租户用户从 Claim 读取）        │
└─────────────────────────────────────────────────────────────────┘
```
