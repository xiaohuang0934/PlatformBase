## 二、核心实现

### 2.1 接口定义

```csharp
/// 通知通道抽象，支持站内信/邮件/短信可插拔扩展
public interface IChannelProvider
{
    /// 通道名称（in_app / email / sms）
    string Channel { get; }

    /// 发送通知
    Task SendAsync(string recipient, string title, string content, CancellationToken ct = default);
}
```

### 2.2 InAppChannelProvider — 站内信实现

```csharp
public class InAppChannelProvider : IChannelProvider
{
    public string Channel => "in_app";

    public Task SendAsync(string recipient, string title, string content, CancellationToken ct)
    {
        // 站内信由 NotificationService 直接入库，此处不重复处理
        return Task.CompletedTask;
    }
}
```

**设计说明：** 站内信不需要"发送"，直接写入 Notifications 表。`InAppChannelProvider` 是一个空实现，实际入库逻辑在 `NotificationService` 中统一处理。这样设计是为了保持 `IChannelProvider` 接口的一致性。

### 2.3 注册方式

```csharp
// Program.cs 中注册所有通道提供者
builder.Services.AddSingleton<IChannelProvider, InAppChannelProvider>();  // 站内信
builder.Services.AddSingleton<IChannelProvider, SmtpChannelProvider>();   // 邮件
```

两个提供者都注册为 Singleton。`NotificationService` 通过注入 `IEnumerable<IChannelProvider>` 获取所有通道，按模板的 `Channel` 字段匹配对应的提供者。

### 2.4 数据模型

**NotificationTemplate — 通知模板**

```csharp
public class NotificationTemplate : TenantAuditableEntity
{
    public string Code { get; set; } = string.Empty;           // 模板编码（唯一）
    public string Name { get; set; } = string.Empty;           // 模板名称
    public string TitleTemplate { get; set; } = string.Empty;  // 标题模板（支持 {变量} 替换）
    public string BodyTemplate { get; set; } = string.Empty;   // 内容模板
    public string Channel { get; set; } = "in_app";            // 发送通道
    public bool IsEnabled { get; set; } = true;                // 是否启用
    public string? Variables { get; set; }                     // 变量说明（如: username,time）
}
```

**Notification — 通知记录**

```csharp
public class Notification : TenantAuditableEntity
{
    public Guid UserId { get; set; }            // 接收用户
    public string Title { get; set; } = "";     // 通知标题
    public string Content { get; set; } = "";   // 通知内容
    public string? TemplateCode { get; set; }   // 关联模板
    public bool IsRead { get; set; }            // 是否已读
    public DateTime? ReadAt { get; set; }       // 已读时间
    public string Channel { get; set; } = "in_app";  // 发送通道
    public DateTime Timestamp { get; set; }     // 通知时间
}
```

## 三、使用示例

### 定义模板（在数据库中配置）

```
Code: "welcome"
Name: "欢迎注册"
TitleTemplate: "欢迎加入 {site_name}！"
BodyTemplate: "亲爱的 {username}，感谢您注册 {site_name}。"
Channel: "in_app"
Variables: "username,site_name"
```

### 发送通知

```csharp
public class UserService
{
    private readonly INotificationService _notificationService;

    public async Task CreateUserAsync(CreateUserDto dto)
    {
        var user = await CreateAndSaveUser(dto);

        // 发送欢迎通知（按模板 Code 查找模板，自动变量替换）
        await _notificationService.SendAsync("welcome", user.Id, new Dictionary<string, string>
        {
            ["username"] = user.Username,
            ["site_name"] = "PlatformBase"
        });
    }
}
```

### 查询通知

```csharp
// 获取当前用户的未读通知
[HttpGet("notifications")]
public async Task<IActionResult> GetMyNotifications()
{
    var userId = _currentUser.UserId.Value;
    var notifications = await _db.Notifications
        .Where(n => n.UserId == userId && !n.IsRead)
        .OrderByDescending(n => n.Timestamp)
        .ToListAsync();
    return Ok(notifications);
}

// 标记已读
[HttpPost("notifications/{id}/read")]
public async Task<IActionResult> MarkAsRead(Guid id)
{
    var notification = await _db.Notifications.FindAsync(id);
    notification.IsRead = true;
    notification.ReadAt = DateTime.UtcNow;
    await _db.SaveChangesAsync();
    return Ok();
}
```

## 四、模板变量替换流程

```
模板: TitleTemplate = "欢迎加入 {site_name}！"
      BodyTemplate = "亲爱的 {username}，感谢注册。"

参数: { "username": "张三", "site_name": "PlatformBase" }

替换后:
  Title = "欢迎加入 PlatformBase！"
  Body  = "亲爱的 张三，感谢注册。"

实现:
  title = Regex.Replace(template.TitleTemplate, @"\{(\w+)\}",
      m => parameters.GetValueOrDefault(m.Groups[1].Value, ""));
```

## 六、最佳实践速查卡

```
┌─────────────────────────────────────────────────────────────────┐
│              站内信通知 黄金法则                                 │
├─────────────────────────────────────────────────────────────────┤
│  1. 通知模板与发送通道解耦（模板只管内容，Channel 决定投递方式）  │
│  2. InAppChannelProvider 是空实现（入库由 NotificationService 做）│
│  3. IChannelProvider 接口支持可插拔扩展（加短信只需新 Provider） │
│  4. 模板变量用 {变量名} 格式，正则替换                           │
│  5. Notification 表记录每一条发送记录（含已读状态）              │
│  6. 已读标记支持 ReadAt 时间追踪                                │
│  7. 多通道同时发送：注入 IEnumerable<IChannelProvider>           │
│  8. Singleton 注册（Provider 无状态）                            │
└─────────────────────────────────────────────────────────────────┘
```
