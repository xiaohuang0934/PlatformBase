# PlatformBase 事件总线 — 手把手教学笔记

---

## 一、什么是事件总线？

**问题：** 用户注册后需要：发欢迎邮件 + 初始化账户 + 记录日志。如果全写在 Register Action 里，代码耦合严重，新增一个步骤就要改 Controller。

**事件总线模式：** 发布者只管"发"事件，不关心谁来"处理"。

```
发布者 (Publisher)                 消费者 (Handlers)
     │                                │
     │  PublishAsync("用户注册")      │
     ├──────────────▶  Channel ───────┤
     │  (立即返回，不等待)            │
     │                                ├── WelcomeEmailHandler  (发邮件)
     │                                ├── InitAccountHandler   (初始化)
     │                                └── AuditLogHandler      (记日志)
```

## 二、核心实现

### 2.1 接口定义

```csharp
// 事件标记接口
public interface IEvent { }

// 事件处理器
public interface IEventHandler<in TEvent> where TEvent : class, IEvent
{
    Task HandleAsync(TEvent @event, CancellationToken ct);
}

// 发布者接口
public interface IEventPublisher
{
    void Register<TEvent, THandler>()
        where TEvent : class, IEvent
        where THandler : IEventHandler<TEvent>;

    ValueTask PublishAsync<TEvent>(TEvent @event, CancellationToken ct = default)
        where TEvent : class, IEvent;
}
```

### 2.2 ChannelEventBus — 完整实现

```csharp
public sealed class ChannelEventBus : IEventPublisher, IDisposable
{
    // System.Threading.Channels 的无界队列（生产者-消费者模式）
    private readonly Channel<object> _channel;

    // 事件类型 → 处理器列表的注册表
    private readonly Dictionary<Type, List<Type>> _handlerRegistry;

    // 后台消费者 Task
    private readonly Task _consumerTask;
    private readonly CancellationTokenSource _cts;

    public ChannelEventBus(IServiceProvider sp, ILogger<ChannelEventBus> logger)
    {
        _channel = Channel.CreateUnbounded<object>(new UnboundedChannelOptions
        {
            SingleWriter = false,   // 多个 Controller 可同时发布
            SingleReader = true     // 单一消费者减少锁竞争
        });
        _handlerRegistry = [];

        // 启动后台消费循环
        _cts = new CancellationTokenSource();
        _consumerTask = Task.Run(() => ConsumeLoopAsync(_cts.Token));
    }

    // 注册事件和处理器
    public void Register<TEvent, THandler>()
        where TEvent : class, IEvent
        where THandler : IEventHandler<TEvent>
    {
        if (!_handlerRegistry.ContainsKey(typeof(TEvent)))
            _handlerRegistry[typeof(TEvent)] = [];
        _handlerRegistry[typeof(TEvent)].Add(typeof(THandler));
    }

    // 发布事件（不等待，立即返回）
    public async ValueTask PublishAsync<TEvent>(TEvent @event, CancellationToken ct)
    {
        if (!_handlerRegistry.ContainsKey(typeof(TEvent)))
        {
            _logger.LogDebug("事件 {EventType} 无注册的处理器，跳过", typeof(TEvent).Name);
            return;
        }
        await _channel.Writer.WriteAsync(@event, ct);
    }

    // 消费循环：读取事件 → 分发到各处理器
    private async Task ConsumeLoopAsync(CancellationToken ct)
    {
        await foreach (var @event in _channel.Reader.ReadAllAsync(ct))
        {
            var eventType = @event.GetType();
            if (!_handlerRegistry.TryGetValue(eventType, out var handlerTypes))
                continue;

            foreach (var handlerType in handlerTypes)
            {
                try
                {
                    using var scope = _serviceProvider.CreateScope();  // 为每个 Handler 创建独立 Scope
                    var handler = scope.ServiceProvider.GetRequiredService(handlerType);
                    var method = handlerType.GetMethod("HandleAsync");
                    await (Task)method.Invoke(handler, [@event, ct]);
                }
                catch (Exception ex)
                {
                    _logger.LogError(ex, "事件处理失败: {EventType} -> {HandlerType}",
                        eventType.Name, handlerType.Name);
                }
            }
        }
    }

    // 优雅关闭
    public void Dispose()
    {
        _cts.Cancel();                       // 通知消费者退出
        _channel.Writer.TryComplete();       // 标记写入完成
        try { _consumerTask.Wait(TimeSpan.FromSeconds(5)); }  // 等待消费完
        catch { }                            // 超时不阻塞进程退出
        _cts.Dispose();
    }
}
```

### 2.3 批量注册（启动扫描）

```csharp
// EventBusExtensions.cs
public static IServiceCollection AddEventBus(this IServiceCollection services, Assembly assembly)
{
    // 扫描程序集中所有 IEventHandler<> 实现
    var handlerTypes = assembly.GetTypes()
        .Where(t => t.IsClass && !t.IsAbstract)
        .SelectMany(t => t.GetInterfaces()
            .Where(i => i.IsGenericType && i.GetGenericTypeDefinition() == typeof(IEventHandler<>))
            .Select(i => new { HandlerType = t, EventType = i.GetGenericArguments()[0] }));

    // 注册所有 Handler 为 Transient
    foreach (var h in handlerTypes)
        services.AddTransient(h.HandlerType);

    // 注册 ChannelEventBus 为单例，并在工厂中调用 Register
    services.AddSingleton<IEventPublisher>(sp =>
    {
        var bus = new ChannelEventBus(sp, sp.GetRequiredService<ILogger<ChannelEventBus>>());
        foreach (var h in handlerTypes)
        {
            // 反射调用 Register<TEvent, THandler>
            var registerMethod = typeof(ChannelEventBus).GetMethod("Register")
                .MakeGenericMethod(h.EventType, h.HandlerType);
            registerMethod.Invoke(bus, null);
        }
        return bus;
    });

    return services;
}
```

## 三、使用示例

### 定义事件

```csharp
public record UserRegisteredEvent(Guid UserId, string Username, string Email) : IEvent;

public record OrderCreatedEvent(Guid OrderId, decimal Amount, Guid UserId) : IEvent;
```

### 实现处理器

```csharp
public class WelcomeEmailHandler : IEventHandler<UserRegisteredEvent>
{
    public async Task HandleAsync(UserRegisteredEvent @event, CancellationToken ct)
    {
        // 发送欢迎邮件（不阻塞注册接口）
        await emailService.SendAsync(@event.Email, "欢迎注册", "...");
    }
}

public class AuditLogHandler : IEventHandler<UserRegisteredEvent>
{
    public async Task HandleAsync(UserRegisteredEvent @event, CancellationToken ct)
    {
        // 记录审计日志
        await logService.WriteAsync($"用户 {@event.Username} 注册成功");
    }
}
```

### 发布事件

```csharp
[HttpPost("register")]
public async Task<IActionResult> Register(RegisterRequest request)
{
    var user = await _userService.CreateAsync(request);

    // 发布事件（异步，不等待处理完成）
    await _eventBus.PublishAsync(new UserRegisteredEvent(user.Id, user.Username, user.Email));

    return Ok(ApiResult.Success("注册成功"));
}
```

## 四、架构全景图

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           事件总线架构                                    │
│                                                                         │
│  Controller.Register()                                                  │
│    │                                                                    │
│    │ _eventBus.PublishAsync(event)                                      │
│    ▼                                                                    │
│  ┌─────────────────────────────────────────────────────────────────┐    │
│  │  ChannelEventBus (Singleton)                                     │    │
│  │                                                                  │    │
│  │  ┌──────────────────┐        ┌──────────────────────────────┐   │    │
│  │  │ Channel<object>  │───────▶│ ConsumeLoopAsync (后台 Task) │   │    │
│  │  │ (无界队列)        │        │                              │   │    │
│  │  │ .Writer.WriteAsync│        │ 读取事件 → 查注册表          │   │    │
│  │  │ (立即返回)        │        │   ├─ CreateScope()          │   │    │
│  │  └──────────────────┘        │   ├─ 解析 Handler            │   │    │
│  │                              │   ├─ 反射调用 HandleAsync    │   │    │
│  │  ┌──────────────────┐        │   └─ try/catch 隔离异常     │   │    │
│  │  │ _handlerRegistry  │        └──────────────────────────────┘   │    │
│  │  │ EventType →       │                                           │    │
│  │  │  [HandlerTypes]   │        Dispose:                             │    │
│  │  └──────────────────┘          Cancel → TryComplete → Wait(5s)    │    │
│  └─────────────────────────────────────────────────────────────────┘    │
│                                                                         │
│  关键特性：                                                              │
│  - SingleWriter=false: 多个发布者并发                                   │
│  - SingleReader=true:  单一消费者减少锁                                  │
│  - 每个 Handler 独立 Scope (隔离 DbContext)                              │
│  - 单个 Handler 异常不影响其他 Handler                                   │
│  - 后期可替换为 RabbitMQ（接口兼容）                                     │
└─────────────────────────────────────────────────────────────────────────┘
```

public class RabbitMqEventBus : IEventPublisher
{

    public ValueTask PublishAsync<TEvent>(TEvent @event, CancellationToken ct) { ... }

builder.Services.AddSingleton<IEventPublisher, RabbitMqEventBus>();  // 替换 ChannelEventBus

## 六、最佳实践速查卡

```
┌─────────────────────────────────────────────────────────────────┐
│              事件总线 黄金法则                                   │
├─────────────────────────────────────────────────────────────────┤
│  1. 事件是"通知"，发布者不关心谁来消费                            │
│  2. PublishAsync 立即返回（fire-and-forget）                     │
│  3. 每个 Handler 在独立 DI Scope 中执行（隔离 DbContext）         │
│  4. 单个 Handler 异常不影响其他 Handler（try/catch 隔离）        │
│  5. 无处理器时仅 LogDebug，不报错                                │
│  6. Channel 无界队列：生产者永不阻塞                             │
│  7. Dispose 等待 5 秒消费完剩余事件                              │
│  8. 反射调用 HandleAsync（编译时类型安全由 Register 保证）        │
│  9. 接口 IEventPublisher 预留 RabbitMQ 替换能力                   │
│ 10. 批量扫描 IEventHandler<> 自动注册                           │
└─────────────────────────────────────────────────────────────────┘
```
